# Калькулятор — офлайн-версия для iPhone

Файлы в этой папке:

- `index.html` — сам калькулятор
- `manifest.webmanifest` — название и иконка для экрана «Домой»
- `sw.js` — сохраняет калькулятор на телефоне, чтобы он работал без интернета
- `icon-180.png`, `icon-192.png`, `icon-512.png` — иконки

## Как выложить на GitHub Pages (бесплатно, один раз)

1. Зарегистрируйтесь на https://github.com (если ещё нет аккаунта).
2. Нажмите **+** → **New repository**. Назовите, например, `calculator`, выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** и перетащите все файлы из этой папки (кроме README.md — его можно не загружать). Нажмите **Commit changes**.
4. Откройте **Settings** → **Pages**. В разделе **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты сверху появится адрес вида `https://ВАШ-ЛОГИН.github.io/calculator/`.

## Как установить на iPhone

1. Откройте этот адрес в **Safari** (с интернетом).
2. Подождите пару секунд, пока страница полностью загрузится.
3. Нажмите **Поделиться** → **На экран «Домой»** → **Добавить**.
4. Запустите калькулятор с иконки один раз, пока есть интернет.

После этого он открывается и считает в авиарежиме.

## Если что-то поменяли в файлах

Загрузите новые файлы на GitHub и увеличьте номер в строке `const VERSION` в файле `sw.js`
(`calc-v1` → `calc-v2`), иначе телефон продолжит показывать старую версию.
